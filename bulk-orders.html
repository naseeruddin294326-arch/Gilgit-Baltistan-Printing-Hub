Photo naming guide

The roll number connects each photo to the correct student record.

  • Excel Roll No: 001 → Photo: 001.jpg
  • Excel Roll No: 002 → Photo: 002.jpg
  • Excel Roll No: 003 → Photo: 003.png
  • Keep each photo file name unique.
  • Use JPG or PNG photos for best results.
